# DSA Concepts & Problems

This repository covers important **Data Structures and Algorithms (DSA)** concepts through problem-solving.

The goal is to build a strong understanding of each concept by implementing and analyzing relevant problems.

Each problem file contains a `main()` method with important test cases to verify the solution.

## Concepts Covered

### 1. Hashing & Prefix Sum

- **Problem 1:** [Longest Subarray with Sum K](./source/hashingPrefixSum/LongestSubarrayWithSumK.java)
- **Problem 2:** [Number of Subarrays with Sum K](./source/hashingPrefixSum/NumberOfSubarraysWithSumK.java)

### 2. Sliding Window
